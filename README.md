
# 📊 Analyse des Scores d'Animes

## 📝 Description
Ce projet consiste en une analyse exploratoire d'un dataset d'animes. L'objectif était de nettoyer les données et de visualiser la distribution des notes attribuées par les utilisateurs.

## 🛠️ Outils utilisés
* **Python** (Pandas pour la manipulation de données)
* **Matplotlib & Seaborn** (pour les visualisations stylées)
* **Google Colab**

## 📈 Visualisations
Le projet inclut un histogramme moderne montrant la répartition des notes, avec une courbe de densité (KDE) pour mieux comprendre les tendances de notation.

## 📂 Contenu du dépôt
* `nom_de_ton_notebook.ipynb` : Le code complet de l'analyse.
* `dataset_clean.csv` : Les données nettoyées prêtes à l'emploi.
